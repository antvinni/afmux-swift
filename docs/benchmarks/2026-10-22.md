## Read-mode review notes (Python reference)

1. A paragraph larger than a chunk is never split, so any log or file
   without blank lines becomes one chunk, overflows the context and the
   whole read exits 1 (reproduced on a 1000- and a 3000-line log).
2. One failed chunk (refusal, timeout) ends the whole read, discarding the
   answers already found.
3. Answers are cited with the whole chunk's line range, not the quote's.
4. Quote verification accepts any substring, so a one-word quote passes.
5. Reads are slow: every chunk is one model call (31 to 44 s for 36k
   tokens), so the skill's "read the file only if nothing useful comes back"
   costs real time compared with grep for exact-string questions.

Swift v2 fixes 1 to 3.
